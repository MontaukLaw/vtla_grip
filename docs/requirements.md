# 需求与验收

## 当前里程碑

1. Windows 能稳定读取 D435 彩色流和深度流。
2. 深度图对齐到彩色图。
3. 用户点击彩色图像素后，程序输出有效深度和相机 XYZ（米）。
4. 无效或越界深度不会生成三维坐标。
5. 能以只读方式访问 RM65 本机 JSON 服务。
6. 未完成标定前，项目拒绝发送机械臂运动命令。
7. 标定采集程序只能连接和读取 RM65 状态，不得使能或移动机械臂。
8. 每个标定样本以追加方式保存相机点、TCP 位姿和关节状态。
9. 通过一个本地 Web 控制台访问相机、标定、机械臂、夹爪、设备状态和日志。
10. DH5 复用 `arm_gripping` 已跑通的 Modbus RTU 协议，支持串口连接、初始化及位置/速度/力命令。
11. 机械臂运动保留配置总开关；RM65 连接并使能后无需额外的会话解锁。自动搬运必须以实际 TCP 位姿连续到位作为进入下一动作的条件。
12. 蓝点到夹爪尖端的Base XYZ补偿必须可调。应用不额外添加安全悬停高度或限制单段移动距离，由 RM65 控制服务和机械臂自身执行运动范围与碰撞限制。
13. 放置 Z 必须在托盘表面 Z 的基础上加入目标物体相对四点标定桌面平面的高度，再叠加夹爪尖端补偿和放置间隙；不得相加两个绝对 Base Z。

## 后续里程碑

- 通过多点标定求取 `T_base_camera`，并用独立点验证误差。
- 自动检测用户指定物体。
- 使用固定末端姿态，低速移动到目标上方安全高度。

## 暂不包含

- 视觉触发的自动下探、夹爪闭合和完整抓取闭环。
- 自动避障和复杂路径规划。
- 任意类别物体的通用识别。
