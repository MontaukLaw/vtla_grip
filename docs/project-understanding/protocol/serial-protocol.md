## DH5 Modbus RTU

默认 115200 baud、8 data bits、无校验、1 stop bit、从站 ID 1，使用 CRC16/Modbus 小端帧尾。功能码为 `0x03`、`0x06`、`0x10`。**代码确认**

| 功能 | 地址 | 范围/含义 |
| --- | ---: | --- |
| 初始化 | `0x0100` | 写 `0x01` 或 `0xA5`，轮询至 0 |
| 力 | `0x0101` | 20–100 |
| 目标位置 | `0x0103` | 0–1000 |
| 速度 | `0x0104` | 1–100 |
| 位置/速度/电流反馈 | `0x0202`–`0x0204` | 各读 1 个寄存器 |
| 故障码 | `0x021F` | 读 1 个寄存器 |

## 左右 Infineon 压力传感器

左右为两个独立 CH343 串口，默认 1,000,000 baud，每侧 32 个 `uint16` 通道，合成为 `left[0:32] + right[0:32]`。**代码确认**

### DATA 帧

| 偏移 | 长度 | 字段 | 来源 |
| ---: | ---: | --- | --- |
| 0 | 4 | ASCII `DATA` | 代码确认 |
| 4 | 1 | 协议版本，必须为 1 | 代码确认 |
| 5 | 1 | 帧类型：1 信号、2 调试 | 代码确认 |
| 6 | 1 | 通道数，必须为 32 | 代码确认 |
| 7 | 1 | 保留 | 代码确认 |
| 8 | 2 | 小端 payload 长度 | 代码确认 |
| 10 | 64/320 | 32 或 160 个小端 `uint16`；调试帧取前 32 个 | 代码确认 |

兼容旧格式：`ALGO` 前 256 字节载荷取前 32 个小端 `uint16`；`STAT` 前 64 字节为状态载荷，不输出压力帧。未发现 CRC。解析器支持分段读取、噪声重同步与超时状态。**代码确认**
