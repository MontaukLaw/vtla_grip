# 项目背景

## 目标

固定在桌面上方约 50 cm 的 RealSense D435 获取指定物体像素与深度，经相机 XYZ、相机到 RM65 Base 外参和蓝点到夹爪尖端补偿，先让机械臂移动到目标上方，后续再加入下降与自动抓取。**用户确认**

## 当前范围

- D435 彩色/深度对齐、点击取点与反投影。**代码确认**
- 末端蓝点标定采集、外参求解和悬停精度门槛。**代码确认**
- RM65 服务、连接、使能、目标预览和受保护运动；无需额外会话解锁，速度可设 1–100。自动搬运在进入下一步前复核实际 TCP 位姿。**代码确认**
- DH5 Modbus RTU 连接、初始化、位置/速度/力控制。**代码确认**
- 左右各 32 通道 Infineon 采集、`arm_gripping` 参数迁移、信号处理和双侧夹取成功判断。**代码确认**
- 指定物体自动识别、下降轨迹、碰撞规划和完整自动抓取状态机仍未完成。**代码确认**

## 关键限制

蓝点到夹爪尖端是固定几何补偿。当前参数保存在 `config/default.json`，传感器参数独立保存在 `config/sensor_processing.json`；保存传感器设置不会改写标定或目标补偿。
