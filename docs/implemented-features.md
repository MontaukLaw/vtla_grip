# VTLA 物体抓取任务——项目功能总结

## 1. 项目简介

本项目实现了一个基于 RealSense D435、RM65 机械臂、DH5 夹爪和双侧压力传感器的桌面物体抓取系统。

用户可以在 Web 界面中完成相机查看、标定、物体识别、设备控制以及自动抓取和放置任务。

## 2. 主要完成的功能

### 2.1 一体化控制界面

- 提供本地 Web 操作界面。
- 集成相机、机械臂、夹爪、压力传感器、标定、视觉数据和日志功能。
- 实时显示设备连接状态和任务执行状态。

### 2.2 相机与坐标定位

- 读取 D435 彩色画面和深度数据。
- 支持在画面中点击位置并获取三维坐标。
- 完成相机坐标到机械臂 Base 坐标的外参标定。
- 标定数据可以保存、继续补点和重新求解。

### 2.3 桌面工作区标定

- 通过鼠标依次点击桌面四个角确定工作范围。
- 根据四个三维点拟合桌面平面，适用于相机斜着拍摄的情况。
- 物体识别和鼠标放置点只在有效桌面工作区内使用。

### 2.4 物体视觉识别

目前支持识别：

- 绿色圆柱体；
- 灰色正方体；
- 绿色实心托盘。

系统能够显示物体框、中心位置、深度和机械臂坐标。存在多个同类物体时，暂时选择其中置信度最高的一个。

### 2.5 视觉训练数据采集

- 可以新增物体类别和场景标签。
- 可以自动框出高于桌面的陌生物体，也可以手动修改标注框。
- 保存彩色图、深度图、YOLO 标签和相关元数据。
- 支持查看、筛选、修改标签和删除历史样本。

### 2.6 机械臂、夹爪和压力传感器控制

- 支持 RM65 连接、使能、读取位姿、运动和慢停。
- 支持 DH5 夹爪连接、初始化、位置、速度和力控制。
- 支持左右两侧压力传感器连接、置零和热力图显示。
- 抓取时通过双侧压力判断是否成功夹住物体。

### 2.7 结构化抓取任务

目前支持以下任务：

- 把绿色圆柱体放入绿色托盘；
- 把灰色正方体放入绿色托盘；
- 把绿色圆柱体或灰色正方体放到鼠标指定的桌面位置。

鼠标指定位置只保存一个，可以随时重新点击覆盖。

执行前系统会先生成搬运预览，用户确认后才开始运动。任务流程包括识别物体、移动到物体上方、下降抓取、触觉确认、抬升、移动到目标位置、下降放置和松开夹爪。

### 2.8 基本安全保护

- 机械臂运动需要配置允许、连接并使能。
- 每次移动后会检查机械臂是否真正到达目标位置，再执行下一步。
- 未成功夹住物体时不会继续前往放置位置。
- 支持任务停止和机械臂慢停。
- 重新设置参数或放置点后，原来的任务预览会失效，需要重新生成。

## 3. 当前基本使用流程

1. 启动相机和机械臂服务。
2. 完成相机外参标定和桌面四点标定。
3. 连接机械臂、夹爪和压力传感器。
4. 选择需要抓取的物体和放置目标。
5. 生成并检查搬运预览。
6. 确认后执行抓取和放置任务。

## 4. 当前还没有完成的功能

- 尚未接入自然语言或 LLM，目前使用界面中的结构化指令。
- 尚未实现利用触觉数据判断物体软硬度。
- 已能采集训练数据，但还没有集成模型训练和模型部署流程。
- 暂不处理严重遮挡、堆叠和复杂避障场景。
- 多个符合条件的物体暂时只抓取一个。



### 结构化任务软硬筛选

- 结构化搬运新增“软硬要求”：不限（默认）、软、硬。
- 选择软或硬后，预览保存同一视觉类别的可抓取候选，先检查推荐目标，再依次检查其他候选。
- 每次夹住后在原抓取高度采集触觉并识别；符合要求才抬起搬运。不符合时原位松开，垂直退回上方，再尝试下一个。
- 每个候选都独立验证；全部不符合时松开最后一个并提示“未找到匹配物体”。识别失败时原位松开并停止任务。
- 界面展示候选数量、当前候选和各次判断结果；选择“不限”时仍按原流程搬运推荐目标。
- 候选位置来自确认的预览，执行期间应保持工作区物体位置不变。候选各自的高度用于计算放置位姿。


### 双侧接触采集与压力数值

- 触觉采集和识别要求双侧数据有效、基线就绪、双侧同时过阈值且确认通过；单侧接触不开始计时或记录。采集期间接触丢失则废弃本次采集。
- 双侧传感器均更新新帧后才推进信号处理和接触确认，失效数据不沿用旧的成功判断。
- 当前接触阈值调整为左右均 10，确认条件为连续 3 个双侧更新帧；可在压力参数中调整。
- 数据管理显示性质、左压力峰值、右压力峰值。峰值为样本全部帧内该侧 32 通道的最大处理值，旧样本读取时动态计算，无需迁移。
- 采集和样本曲线按左、右两行显示单帧通道峰值，采用相同显示量程，标注纵轴范围和秒数；读数未换算为 N 或 kPa。
- 压力页各通道显示处理后数值，悬停可查看原始/处理/显示值；另显示配置颜色量程、原始峰值、基线状态及最近置零时间。
- 2026-09-11 经用户确认夹爪完全张开且空载后现场置零：处理峰值由左约 32.2、右约 272.0 降为双侧 0，连续约 3 秒检查无接触误判。此次空载残余可由重新置零消除；不是原始 ADC 数值必须为零。
- 每次夹爪执行完全张开并等待松爪时间后，结构化搬运和触觉采集都会尝试自动更新空载零点；没有双侧新帧时只记录警告，不阻塞松爪。
- 夹爪完全张开后立即调零；不再额外等待松爪或调零后的固定基线稳定时间。机械臂到位只做 1 次稳定确认，移动到下一个物体的过程用于自然建立双侧基线，接触判断仍要求双侧基线就绪。
- 结构化搬运默认不再在 `move_to_pose` 返回后重复轮询 TCP 位姿（`wait_for_arrival_feedback=false`），用于验证重复到位确认是否造成阶段停顿；需要恢复时将该配置改为 `true`。

### 控制台夹爪压力监视

- 闭合指令到达下限后仍未确认双侧接触时，搬运和触觉采集保持闭合并继续读取反馈，不再因此自动松开。确认接触后继续流程；用户可停止等待。保持期间每秒记录一次闭合反馈。
- 闭合下限现在以 DH5 的实际位置反馈判断。即使目标指令已经是 100，只要实际位置仍大于 100，程序会继续发送闭合指令并读取实际位置。

- 主控制台右侧保留结构化搬运指令，并新增左右夹爪压力监视区。
- 左夹爪、右夹爪各有一张独立实时图，同时绘制该侧 32 通道总压力和通道峰值压力。
- 每张图显示当前量程、当前总和、当前峰值及图例；数据每 250 ms 刷新，保留最近 100 个点。
- 右侧原有的目标坐标、视觉识别、抓取流程和系统状态卡片从主控制台隐藏，详情仍可通过对应面板查看。
