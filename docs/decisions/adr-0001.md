# ADR-0001：Windows、Python 3.12 与本机 RM65 服务

## 状态

已采用。

## 决策

- 第一版使用 Windows 和 64 位 Python 3.12，由 `uv` 管理虚拟环境。
- RealSense 使用官方 `pyrealsense2`，图像交互使用 OpenCV。
- 不复制 RM65 SDK；视觉项目通过现有本机 JSON 行服务访问机械臂。
- 真机运动默认关闭，只有完成外参标定和安全验收后才能显式启用。

## 原因

当前 D435 和 RM65 控制代码都已能在 Windows 工作。现有 RM65 服务统一处理 SDK、
单位转换、反馈与逆解，复用它能减少重复硬件控制逻辑和安全风险。
