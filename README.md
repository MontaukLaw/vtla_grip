# VTLA Grip

RealSense D435、睿尔曼 RM65 与 DH5 夹爪的本地视觉抓取控制台。当前版本已把相机、蓝点标定采集、机械臂基础控制、夹爪串口控制、设备状态和日志集成到一个 Web 界面中。

## 一键启动

环境：Windows 10/11、Python 3.12、Node.js 22+、`uv`，以及 Intel RealSense SDK/驱动。

首次安装：

```powershell
cd C:\ai\VTLA_grip
uv sync --extra dev
cd frontend
npm install
```

以后从项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_app.ps1
```

浏览器会打开 `http://localhost:3000`。停止后台服务：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\stop_app.ps1
```

## 当前工作流

1. 在“相机”中启动 D435，在主画面点击机械臂末端蓝点。
2. 启动 RM65 服务并连接机械臂；标定采集只读取当前 TCP/关节状态。
3. 在“标定采集”中开始会话，改变机械臂姿态后保存至少 10–15 组分布良好的样本。结束后可以点击“继续采集”向同一记录补点，已有点数不会清零；只有“新建记录”会切换到新的空记录。
4. 数据记录到 `records/calibration/blue-dot-*.jsonl`。蓝点到真实 TCP 的固定偏移仍需在求解阶段处理。
5. 完成外参求解和验证后，才能生成物体上方目标点并允许机械臂低速移动。

在“压力传感”弹窗中可连接左右 CH343 串口、空载置零并查看两张 8×4 热力图。置零时夹爪必须处于完全空载状态。当前电脑检测到 COM68、COM69；首次使用需按压左侧确认左右映射，若热力图相反就在界面交换两个端口。

## 第一版桌面视觉识别

启动 D435 后先点击主画面右上角“标定工作区”，依次点击桌面工作区的左上、右上、右下、左下四个角。系统会保存每一点的像素、深度、Camera XYZ 和 Base XYZ，拟合桌面平面，并在画面中显示红色四边形。四点最大平面残差必须不超过 15 mm；标定失败不会覆盖上一次有效结果。标定结果保存在 `config/table_workspace.json`。

随后点击“识别物体”，系统只在四点图像多边形内识别，并使用拟合后的三维桌面边界再次验证目标坐标。尚未标定工作区时，会回退使用 `vision.roi_xyxy` 矩形区域。第一版识别：

- 竖直放置的绿色圆柱体；
- 灰色正方体；
- 作为放置目标的绿色实心托盘。

识别结果包含轮廓框、像素中心、深度、相机坐标；外参通过质量门槛时还会输出 Base 坐标。多个可抓取物体同时满足条件时只推荐置信度最高的一个。灰色正方体不会再只依赖全局灰色阈值，而是结合局部明暗对比、低饱和度、透视下的多边形轮廓和目标内部深度一致性，从同样偏灰的桌面中分离目标。绿色实心托盘使用面积、饱和度、透视矩形比例和四边形轮廓联合识别，避免与竖直绿色圆柱混淆。轮廓接触 ROI 边界时仍会显示识别框，但不会推荐抓取或放置；深度无效、深度跨度过大或疑似粘连时也会拒绝生成推荐点。现场颜色、面积和形状阈值可在 `config/default.json` 的 `vision` 节调整；灰色目标的局部对比参数为 `gray_adaptive_block_px` 和 `gray_adaptive_c`，托盘参数使用 `tray_*` 前缀。

## 结构化指令搬运

第一版不接入 LLM，目标物体支持绿色圆柱体和灰色正方体，放置目标支持绿色托盘或一个鼠标指定位置。选择“鼠标指定位置”后点击“标定放置点”，再在视频中的桌面工作区内点击放置中心；系统会把点击射线投影到已标定桌面平面并保存该点，重新标定会覆盖旧点。使用顺序：

1. 启动 D435，确保四点桌面工作区和相机到 Base 外参有效。
2. 连接 RM65、DH5 和双侧压力传感器，并使能 RM65；应用不再要求额外的会话解锁。
3. 在主界面“结构化搬运指令”中选择目标，点击“生成搬运预览”。
4. 检查目标框、托盘框、抓取/放置坐标和动作步骤，再点击“确认执行”。
5. 状态机依次执行：张开与触觉调零 → 目标上方 → 抓取高度 → 逐步闭合到双侧接触 → 抬升 → 托盘上方 → 放置高度 → 松开 → 抬升。

多个同类目标只搬运置信度最高的一个。未检测到双侧接触时，夹爪会张开、机械臂抬回目标上方并终止，不会继续前往托盘。运行中点击“停止”或顶部“紧急慢停”会请求 RM65 慢停；如果状态显示夹爪可能仍持有物体，不会自动松开，以免物体坠落。

搬运速度和高度可在“设置 → 自动搬运速度与高度”中保存，后端会立即应用并原子写入 `config/default.json` 的 `transfer` 节。可调项目包括水平搬运速度、垂直升降速度、独立抓取高度微调、抓取后抬升、托盘上方距离和松开放置间隙。抓取高度微调为 `0 mm` 时使用“视觉目标 Base Z + 蓝点到夹爪尖端固定补偿”；正值抬高、负值降低。保存后旧预览自动失效，必须重新生成。首次真机验证应保持低速，并逐点确认这些高度与现场 Base Z 正方向一致。

放置高度使用四点桌面平面估算物体原始高度：`托盘表面 Z + 物体相对桌面高度 + 夹爪尖端 Z 补偿 + 放置间隙`。搬运预览会显示本次采用的物体桌面高度。

## 视觉训练数据采集

左侧打开“视觉数据”面板后，先选择一个已有训练类别，或直接添加一种系统从未见过的新物体类别。采集阶段不再依赖颜色和形状识别，而是利用四点标定得到的桌面平面，从深度图中寻找高于桌面的连通区域，因此可以自动框出陌生物体。默认检测高度为 12–350 mm，面积为 350–80000 px，可在 `config/default.json` 的 `vision.proposal_*` 参数中调整。

自动框可人工确认和修正：点击已有框可删除误框，在画面空白处拖拽可以补框，“恢复自动框”会放弃手工修改并重新采用深度候选框。互相接触的物体第一版会形成一个连通框，建议分开放置或手工修正。空桌面使用独立的负样本开关，并且只有深度算法未发现桌面物体时才能保存。

确认自动框后点击“确认自动框并保存”。每次采集保存到 `records/vision_dataset/YYYYMMDD/<sample-id>/`：

- `color.png`：D435 对齐彩色帧，BGR8；
- `depth.png`：与彩色图对齐的 16 位 Z16 原始深度；
- `color.txt`：与 `color.png` 同名配对的 YOLO 检测标签，每个实例一行；空桌面负样本为空文件；
- `metadata.json`：标签、深度比例、相机内参、工作区四点、外参和视觉配置。

数据集根目录同时生成 `classes.json` 和 `classes.txt`。前三个类别编号继续固定为 `green_cylinder`、`gray_cube`、`green_tray`；新增训练类别只会追加编号，不会重排旧数据。自定义场景标签与训练类别独立，不参与 YOLO 类别编号。面板下方的历史样本库支持按标签筛选、查看彩色图和伪彩深度预览、展开完整元数据、修改样本标签以及删除单个样本。删除前会二次确认，样本目录只会移动到 `records/vision_dataset/.trash/`，不会立即永久清除。当前生成的是目标检测边界框；只有将来改用实例分割模型时，才需要额外绘制精细轮廓。

手动重新求解最新标定记录：

```powershell
uv run vtla-solve-calibration
```

报告保存到 `config/calibration.json`。只有验证 RMS ≤ 10 mm 且最大误差 ≤ 15 mm 时才标记为可进行悬停验证。

## 蓝点补偿与首次悬停

“设置”弹窗中分别配置：

- 蓝点到夹爪尖端的 Base XYZ方向距离，X/Y/Z均可在界面设置。

视觉目标使用：

```text
目标位姿XYZ = 外参映射结果 + [ΔX, ΔY, ΔZ]
```

运动配置允许后，RM65 连接并使能即可执行，不再要求额外的会话解锁。应用保留速度上限并要求先计算和检查目标预览，不再额外限制单段移动距离；运动范围与碰撞限制由 RM65 控制服务和机械臂自身负责。

## 安全边界

- API 只监听 `127.0.0.1:8000`，不应暴露到局域网或公网。
- `config/default.json` 的 `robot.allow_motion` 默认是 `false`。
- 配置允许运动后，每次服务重启仍需连接并使能 RM65，但无需手动解锁。
- 顶栏“紧急慢停”始终可见；慢停与失能继续由 RM65 控制服务处理。
- DH5 初始化和位置命令会造成真实夹爪动作，操作前清空夹爪周围区域。
